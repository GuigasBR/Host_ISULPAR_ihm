Banco de Dados

1. Ementa da Disciplina

Banco de Dados é uma área da Computação dedicada ao estudo, à organização, ao armazenamento e ao gerenciamento de informações. Seu objetivo é permitir que os dados sejam armazenados de maneira estruturada, facilitando consultas, atualizações, pesquisas e o acesso seguro às informações.

Os bancos de dados estão presentes em praticamente todos os setores da sociedade, como sistemas bancários, lojas virtuais, hospitais, redes sociais, instituições de ensino e empresas. Sempre que um sistema precisa armazenar informações de usuários, produtos, transações ou registros, existe a possibilidade de utilização de um banco de dados.

Compreender essa área significa conhecer como os dados são organizados, como podem ser manipulados e quais tecnologias permitem garantir sua integridade, segurança e disponibilidade.

Ementa

Carga Horária: 80h

Estudo dos fundamentos de Banco de Dados, conceitos de armazenamento e organização de informações. Introdução aos modelos de dados, modelagem conceitual, lógica e física. Estudo do modelo relacional, tabelas, registros, atributos, chaves primárias e estrangeiras. Linguagem SQL para criação, consulta, atualização e exclusão de dados. Introdução à normalização, relacionamentos entre tabelas, integridade referencial, transações e sistemas gerenciadores de banco de dados. Discussão sobre segurança, controle de acesso, backup e recuperação de informações.

Objetivo Geral

Compreender os fundamentos de Banco de Dados e desenvolver conhecimentos para projetar, organizar e manipular informações de maneira eficiente, utilizando modelos de dados e linguagens de consulta. Desenvolver também uma visão crítica sobre a importância da segurança, integridade e disponibilidade das informações nos sistemas computacionais.

Objetivos Específicos

  • Compreender os conceitos básicos e a importância dos bancos de dados.
  • Conhecer os diferentes modelos de organização e armazenamento de informações.
  • Entender os princípios da modelagem conceitual, lógica e física de dados.
  • Identificar os elementos do modelo relacional, como tabelas, campos, registros e chaves.
  • Aprender a utilizar a linguagem SQL para manipular e consultar informações.
  • Compreender os relacionamentos entre tabelas e os processos de normalização.
  • Conhecer os princípios de integridade, segurança, backup e recuperação de dados.
  • Desenvolver habilidades para projetar e administrar bancos de dados utilizados em aplicações reais.

Principais Tópicos Estudados

  • Fundamentos de Banco de Dados: conceitos, características, organização e importância dos dados nos sistemas computacionais.
  • Modelagem de Dados: conceitos de modelagem conceitual, lógica e física.
  • Modelo Relacional: tabelas, registros, atributos, chaves primárias e estrangeiras.
  • Linguagem SQL: comandos de criação, consulta, atualização e exclusão de dados.
  • Normalização: processos de normalização e relacionamentos entre tabelas.
  • Integridade e Segurança: princípios de integridade referencial, segurança, backup e recuperação de dados.

O que o estudante pode desenvolver?

Ao estudar Banco de Dados, o estudante pode desenvolver raciocínio lógico, capacidade de organização de informações, conhecimento em modelagem de dados e habilidade para trabalhar com consultas e comandos SQL.
A disciplina também contribui para a compreensão de como os sistemas computacionais armazenam e utilizam informações, permitindo que o estudante desenvolva projetos envolvendo cadastros, registros, consultas e gerenciamento de dados. Além disso, estimula a resolução de problemas relacionados à eficiência, segurança e integridade das informações.

Possíveis Caminhos Profissionais

O conhecimento em Banco de Dados é importante para diversas áreas da Tecnologia da Informação. Sua aplicação está presente no desenvolvimento de sistemas, na administração de infraestrutura tecnológica e no gerenciamento de grandes volumes de informações.

  • Administrador de Banco de Dados (DBA): responsável pela instalação, configuração, manutenção, segurança e desempenho dos bancos de dados.
  • Desenvolvimento de Software: criação de sistemas e aplicações que utilizam bancos de dados para armazenar e consultar informações.
  • Análise de Dados: organização, consulta e interpretação de informações para auxiliar empresas na tomada de decisões.
  • Engenharia de Dados: desenvolvimento de estruturas e processos para coletar, armazenar, transformar e disponibilizar grandes volumes de dados.
  • Business Intelligence (BI): utilização de dados para criar relatórios, indicadores e análises que auxiliam no planejamento empresarial.
  • Arquitetura de Dados: planejamento e estruturação de soluções para armazenamento, integração e gerenciamento de informações.
  • Segurança da Informação: proteção dos dados contra acessos não autorizados, vazamentos, perdas e outras ameaças.

Essas possibilidades não representam uma garantia de emprego ou uma lista definitiva de profissões. São exemplos de áreas nas quais os conhecimentos em Banco de Dados podem ser aplicados.

3. Case de Sucesso

O comércio eletrônico é uma das áreas que mais dependem de bancos de dados para funcionar. Grandes empresas precisam armazenar informações sobre clientes, produtos, compras e pagamentos, além de utilizar esses dados para compreender o comportamento dos consumidores. Um exemplo brasileiro é o Magazine Luiza, que utiliza tecnologias de análise de dados para melhorar a experiência de compra e apoiar suas decisões comerciais.

Big Data e Banco de Dados no Magazine Luiza

O problema inicial

Com o crescimento das vendas pela internet, o Magazine Luiza passou a lidar com um volume cada vez maior de informações sobre seus consumidores e suas operações comerciais.

Dados como histórico de compras, produtos pesquisados, valores pagos e preferências dos clientes representam informações importantes para o funcionamento do negócio.

O desafio era transformar esse grande volume de informações em conhecimento útil, permitindo compreender melhor o comportamento dos consumidores e oferecer recomendações de produtos mais adequadas.

A solução

Para enfrentar esse desafio, a empresa investiu em ferramentas de Big Data e análise de informações por meio de seu laboratório de tecnologia e inovação, o Luizalabs.

Um dos projetos desenvolvidos foi o Bob, voltado ao aprimoramento do sistema de recomendações de produtos. A proposta era utilizar informações sobre os consumidores e seus interesses para identificar padrões de comportamento e sugerir produtos de acordo com suas preferências.

Com a utilização dessas tecnologias, os dados armazenados pela empresa passaram a ter um papel ainda mais estratégico, contribuindo para personalizar a experiência de compra e apoiar as decisões comerciais.

Resultados observados

O estudo acadêmico realizado sobre o Magazine Luiza identificou benefícios e desafios relacionados à adoção de Big Data no varejo virtual.

Entre os principais resultados e contribuições observados, destacam-se:

  • Melhor compreensão do comportamento dos consumidores.
  • Aprimoramento do sistema de recomendação de produtos.
  • Utilização de informações para apoiar estratégias comerciais.
  • Maior integração entre tecnologia e áreas de negócio.
  • Transformação dos dados em informações úteis para a tomada de decisões.

O estudo também identificou que a implantação dessas tecnologias exige planejamento, participação das equipes envolvidas e alinhamento com os objetivos da empresa.

O que esse case ensina?

  • Bancos de dados são fundamentais para armazenar e organizar informações utilizadas pelas empresas.
  • Grandes volumes de dados podem ajudar a identificar padrões e compreender o comportamento dos consumidores.
  • A análise de informações pode contribuir para melhorar serviços e experiências de compra.
  • A escolha das tecnologias deve considerar as necessidades e os objetivos de cada organização.
  • O uso de dados exige planejamento, segurança e responsabilidade no tratamento das informações.

5. Registro de Seminário

Tema do Seminário: Segurança, Privacidade e Integridade em Bancos de Dados

Contextualização

Os bancos de dados armazenam informações importantes para o funcionamento de empresas, instituições e sistemas computacionais. Dados pessoais, informações financeiras, registros de clientes e históricos de transações são alguns exemplos de informações que precisam ser armazenadas e protegidas.

Entretanto, o armazenamento dessas informações também envolve riscos. Acessos não autorizados, vazamentos, alterações indevidas e perda de dados podem causar prejuízos financeiros e comprometer a privacidade dos usuários.

Por isso, a administração de bancos de dados exige cuidados relacionados à segurança, ao controle de acesso e à integridade das informações.

Objetivo do seminário

Analisar a importância da segurança e da privacidade em bancos de dados, discutindo os principais riscos relacionados ao armazenamento de informações e as medidas utilizadas para proteger os dados contra acessos indevidos, alterações e perdas.

Roteiro da apresentação

  1. Introdução: apresentar o conceito de Banco de Dados e sua importância no armazenamento de informações.
  2. Como os dados são armazenados: explicar como as informações são organizadas em tabelas, registros e relacionamentos.
  3. O que é segurança em Banco de Dados? apresentar os mecanismos utilizados para proteger informações armazenadas.
  4. Principais riscos: discutir situações como vazamentos, ataques cibernéticos, exclusão acidental e acessos não autorizados.
  5. Privacidade e responsabilidade: abordar a importância da proteção de dados pessoais e a relação com a Lei Geral de Proteção de Dados (LGPD).
  6. Possíveis medidas de proteção: apresentar recursos como senhas, permissões de acesso, criptografia, backups e monitoramento.
  7. Conclusão: destacar que a segurança deve fazer parte de todas as etapas de criação, utilização e administração de um banco de dados.

Síntese das discussões

A discussão evidencia que proteger um banco de dados não significa apenas impedir que pessoas desconhecidas tenham acesso às informações. Também é necessário garantir que os dados permaneçam corretos, disponíveis e acessíveis somente por pessoas autorizadas.

Outro ponto importante é que falhas de segurança podem ocorrer tanto por ataques externos quanto por erros humanos, como a utilização de senhas fracas, permissões configuradas incorretamente ou ausência de cópias de segurança.

Também foi considerada a importância da LGPD, legislação brasileira que estabelece regras para o tratamento de dados pessoais. Empresas e instituições precisam adotar medidas para garantir que as informações sejam utilizadas de maneira adequada e segura.

Perguntas para debate

  • Quais podem ser as consequências de um vazamento de dados pessoais?
  • Como uma empresa pode impedir que funcionários tenham acesso a informações que não são necessárias para suas funções?
  • Por que realizar backups regularmente é importante?
  • Qual é a responsabilidade das empresas na proteção dos dados de seus clientes?
  • Como equilibrar facilidade de acesso, segurança e privacidade das informações?

Conclusão do seminário

A segurança de bancos de dados é fundamental para garantir a confiabilidade dos sistemas e proteger as informações armazenadas. A utilização de mecanismos de proteção, políticas de acesso e cópias de segurança ajuda a reduzir riscos e evitar prejuízos.

Compreender esses cuidados é essencial para qualquer profissional que trabalhe com tecnologia, pois a proteção das informações deve ser considerada desde o planejamento até a utilização de um banco de dados.

6. Storytelling

Contexto — uma loja com milhares de informações

Imagine uma loja virtual que realiza centenas de vendas diariamente. A empresa precisa armazenar informações sobre clientes, produtos, pedidos, pagamentos e entregas. Todos esses dados são importantes para manter o funcionamento da loja e garantir que os clientes recebam seus produtos corretamente.

No início, a empresa utilizava planilhas para registrar as vendas e controlar o estoque. Com o crescimento do negócio, esse processo começou a apresentar dificuldades, como informações duplicadas, registros desatualizados e demora para localizar determinados dados.

Conflito — o problema da organização das informações

Em um dia de grande movimento, a loja recebe diversos pedidos ao mesmo tempo. Alguns produtos aparecem disponíveis no site, mesmo depois de terem sido vendidos. Além disso, a equipe encontra dificuldades para localizar o histórico de compras de determinados clientes.

A situação começa a gerar atrasos, reclamações e problemas no controle do estoque.

O desafio não é apenas armazenar mais informações, mas garantir que elas estejam organizadas, atualizadas e disponíveis quando forem necessárias.

Decisão — implementar um Banco de Dados

A empresa decide implementar um Sistema Gerenciador de Banco de Dados (SGBD), utilizando o MySQL para organizar suas informações.

Os dados passam a ser separados em tabelas relacionadas, como clientes, produtos, pedidos e pagamentos. Cada registro possui identificadores próprios, e os relacionamentos permitem conectar informações de diferentes tabelas.

A equipe também utiliza comandos SQL para consultar pedidos, atualizar estoques, cadastrar novos clientes e acompanhar as vendas realizadas.

Resultado — uma operação mais organizada

Com a implementação do banco de dados, a empresa consegue centralizar suas informações e facilitar o gerenciamento das operações.

O controle de estoque passa a ser atualizado conforme as vendas são realizadas, os funcionários conseguem consultar o histórico de pedidos com mais facilidade e as informações dos clientes ficam organizadas em uma estrutura centralizada.

Para verificar os benefícios da mudança, a empresa acompanha indicadores como quantidade de erros nos registros, tempo necessário para localizar informações, divergências no estoque e velocidade de processamento dos pedidos.

Os resultados devem ser avaliados após a implantação, considerando as condições anteriores e posteriores à utilização do novo sistema.

Aprendizado

A experiência demonstra que um banco de dados bem estruturado pode melhorar significativamente a organização e o funcionamento de uma empresa. Entretanto, sua eficiência depende de um bom planejamento, da escolha adequada das tecnologias e da manutenção das informações.

O principal aprendizado é que os bancos de dados não servem apenas para guardar informações. Eles permitem relacionar, consultar, atualizar e administrar dados que são fundamentais para as atividades de uma organização.
